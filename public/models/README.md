# GRIDLINE – 3D model assets

Ide kerülnek a 3D modellek. A webes útvonalak a `public` mappához képest indulnak, például `/models/cars/bmw.glb`.

- Autók: `cars/`
- Tuning: `tuning/wheels/`, `spoilers/`, `bodykits/`, `bumpers/`, `other/`
- Előnézeti képek: `thumbnails/`

Csak olyan modelleket használj, amelyek licencük engedi a projektben való felhasználást.
